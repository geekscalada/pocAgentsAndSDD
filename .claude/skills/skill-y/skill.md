# Skill Y — Generación Guiada

Esta skill te proporciona un método para producir contenido nuevo de forma estructurada y coherente.

## Cuándo usarla

- Cuando necesites generar texto, listas o documentos a partir de instrucciones o contexto.
- Cuando la tarea requiera un estilo, tono o formato específico.
- Cuando debas expandir, reformular o completar contenido existente.

## Método de aplicación

Al aplicar esta skill, sigue estos pasos:

1. **Clarificar el objetivo**: ¿qué debe producir exactamente el output?
2. **Definir el formato**: ¿es un párrafo, una lista, una tabla, un esquema?
3. **Identificar el tono**: ¿formal, técnico, divulgativo, neutro?
4. **Generar un borrador**: produce el contenido siguiendo las restricciones anteriores.
5. **Revisar coherencia**: comprueba que el output cumple el objetivo y es consistente.

## Formato de salida

Devuelve directamente el contenido generado, sin preámbulos ni explicaciones sobre tu proceso.
